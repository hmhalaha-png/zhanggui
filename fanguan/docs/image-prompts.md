# 风格样张：ChatGPT 生图提示词

我的样张是用代码画的示意图。下面的提示词用来在 ChatGPT（或其他生图工具）里生成**同一个场景**的四种风格，帮你判断每种风格最好能做到什么程度。

## 用法

1. 先发「共同场景」，再接上一种风格的描述，一起发给 ChatGPT。
2. 每种风格生成 2～3 张，挑最好的一张。
3. 生成好的图放进仓库的 `fanguan/docs/concepts/` 目录，文件名用 `a-1.png`、`d-2.png` 这样的格式，然后告诉我。
4. **画面里不要有文字。** AI 写的汉字经常出错；游戏里的招牌、菜牌、对话都由代码来写。

## 共同场景

```
一家中国古代小饭馆的游戏画面，横屏，宽高比 16:9。
去掉正面的墙和屋顶，能看到店里：左边是柜台，掌柜在打算盘，柜台后面墙上挂着菜牌，旁边堆着酒坛；
中间摆着几张八仙桌和长凳，坐着各种身份的客人：书生、穿红袍的官员、戴尖帽的西域使者、两个喝酒的地痞；
店小二端着托盘在桌子之间走；右后方是厨房，有砖砌的灶台、两口铁锅、冒着蒸汽，厨子在炒菜；
门口挂着红灯笼，门外立着一面写着酒字的酒旗（旗上不要写字，留白），街上有挑担的小贩。
季节是秋天，时间是下午，暖色阳光。
画面中不要出现任何文字、字母、水印或界面元素。
```

## A：2.5D 等距古风

```
视角：2.5D 等距俯视（2:1 等距），镜头固定，能看到店内全貌。
画风：精致的手绘国风插画，参考宋代风俗画的配色——赭黄色土地、黛灰色瓦、朱红色柱子、少量青绿点缀；
柔和的阴影，干净细腻的线条，带一点绢纸质感；人物小巧，大约占画面高度的十分之一。
```

## B：像素风

```
视角：正面俯视、剖开的店堂，类似开罗游戏的模拟经营画面。
画风：像素画，有限的暖色调色板（约 24 色），人物是两头身的 Q 版小人，
每个像素清晰可见，不要模糊、不要抗锯齿、不要渐变。
```

## C：3D 低多边形

```
视角：正交等距视角（像模拟经营手游那样的固定斜俯视）。
画风：3D 低多边形（low poly），平面着色，温暖的游戏渲染光照，灯笼发出橙色光，地面有柔和的投影；
整体像一款精致的手机模拟经营游戏截图，配色偏古风（木色、朱红、黛瓦）。
```

## D：横版剖面

```
视角：正侧面的横版剖面，一栋两层的饭馆像玩具屋一样去掉了正面墙。
一楼：门口、柜台、楼梯、大堂、厨房；二楼：用屏风隔开的雅间，以及说书台和听书的客人。
屋顶是起翘的飞檐，檐下有彩绘斗拱，背景是傍晚的远山。
画风：工笔画、绢本设色的质感，线条精细，颜色典雅。
```

## 单个素材怎么生成（选定风格以后再用）

如果选了 A 或 D，后面需要单张透明背景的素材。每个素材都用同样的格式：

```
[和样张一致的风格描述]
单个物件：[比如：一张中国古代的八仙桌，配两条长凳]
透明背景，物件居中，完整不裁切，光线从左上方照来，[A：2:1 等距视角 / D：正侧面视角]。
不要文字，不要阴影以外的背景。
```

先生成一张放进游戏里试，确认角度、大小、画风都对了，再批量生成。
