# 古代饭馆模拟器 · 策划（阶段 0-1，第二稿）

> 状态：**待你审**。审过之前不写游戏代码。
> 已定：
> - 美术风格 A（2.5D 等距古风），时代是北宋，只做安卓手机横屏。

## 一句话

北宋，汴京城外的汴河岸边。你在官道旁撑起一个布棚、摆几张桌子，卖茶和简单的饭食给过路的挑夫、船夫和赶考的书生。攒够了钱就扩成路边脚店，再进汴京城盘下铺面，最后做成能自己酿酒的正店。

> 史实上：
> - 《东京梦华录》记载汴京有「正店七十二户，此外不能遍数，其余皆谓之脚店」。
> - 只有正店能自己酿酒，脚店的酒要从正店进货。这正好对上「酒先从外面进货，后来自酿做招牌」。
> - 《清明上河图》开头画的正是城外：汴河、柳岸、虹桥，路边有许多小摊和脚店。

## 核心循环（茶摊阶段）

**一天**（约 12 分钟现实时间，打开菜单时暂停）：

| 时辰 | 做什么 |
|---|---|
| 卯时（清晨） | 去村里早集买菜；渔船靠栈桥时，可以直接从渔夫手里买鲜鱼。都能讨价还价 |
| 辰～巳时 | 生火烧水、蒸炊饼、备菜，定今天卖什么 |
| 午～申时 | 过路客陆续来：点茶点饭、上菜、收钱；客船靠岸时会一下子来一波客人 |
| 酉时 | 收摊前最后一波：赶路的人、收工的农人 |
| 戌～亥时 | 收摊、洗碗、记账、睡觉（自动存档） |

**信息线**：客人闲聊会透露菜价涨跌、征夫修堤、科举开考、节庆、天气等消息。这些会影响之后几天的菜价和客流；会听的店家赚得多。

## 开局的吃食（初定，阶段 4 再细考据）

| 吃食 | 说明 |
|---|---|
| 茶 | 路边卖的是煮的粗茶；城里茶坊那种「点茶」等进城后再做 |
| 饮子 | 甘草汤一类的草药饮，宋代街头常见；夏天卖冰雪凉水 |
| 炊饼 | 就是蒸饼。宋仁宗名赵祯，「蒸」与「祯」音近，避讳改叫炊饼 |
| 胡饼 | 芝麻烧饼 |
| 汤饼 | 面片汤 / 汤面 |
| 馄饨 | |
| 鱼羹 | 用河边现买的鱼做 |
| 腌菜 | 下饭小菜 |
| 村酒 | 从城里正店进的，脚店不能自己酿 |

不出现辣椒、玉米、土豆、番茄，这些宋代还没有。

## 世界与编辑器

- **世界**：一片可以自由走动、大小有限的区域。开局是汴河岸边的一段，进城后是汴京的一条街。内容由你在编辑器里搭。
- **编辑器**：在电脑浏览器里用鼠标操作。
  - 能做的事：铺地面（土路、草地、水面、泥岸）；摆放树木、芦苇、棚子、桌凳、坛罐；标出哪里能走。
  - 结果存成一个地图文件放进仓库，手机上的游戏直接读取。
- **搭场景不花这里的 token**：你用鼠标摆出来的是数据文件。我的 token 主要花在写引擎、编辑器和玩法上。
- **先做编辑器不是绕路**：游戏里玩家摆摊、扩建，用的就是这套摆放系统。
- **物件要能换图**：每个物件先用代码画（像样张 E），以后可以在编辑器里换成 ChatGPT 生成的图，摆好的场景不用重搭。

## 美术

- 风格 A：2:1 等距、暖色调、低对比。视角、比例、色板和画法规则见 [reference-breakdown.md](reference-breakdown.md)。
- **人物**：用代码画（已定）。约 7 头身，衣服、帽子、发型可以组合，动作也由代码控制。
- **场景物件**有两条路：

  | | 全部用代码画（样张 E 的做法） | 物件用 ChatGPT 生成 |
  |---|---|---|
  | 画风统一 | 天然统一 | 要靠提示词反复试 |
  | 精细度 | 有上限：偏平涂，离参考图还有明显差距 | 能接近参考图 |
  | 谁来做 | 我，花这里的 token | 你，花 ChatGPT 的用量和抠图的时间 |
  | 改起来 | 改代码就行，比如改颜色、改大小 | 要重新生成 |
  | 和代码画的人物放在一起 | 搭 | 可能不搭 |

  **我的建议**：第一版先全部用代码画，水平就是样张 E 这样，足够把玩法做出来、在手机上试。编辑器支持换图，等玩法定了，再挑几样最显眼的物件（布棚、灶台、柳树）用 ChatGPT 试做，放在一起比较，再决定换不换。
- 文字一律由代码写，不让 AI 画字。
