## 一句话

北宋汴京，你接手了虹桥边一家快倒闭的小**脚店**。每天天不亮去早市买菜、讨价还价，回店做菜招待客人，从客人的闲聊里听出行情，把它一步步做成能自己酿酒的**正店**。

> 史实上：《东京梦华录》记载汴京有「正店七十二户，此外不能遍数，其余皆谓之脚店」。只有正店有官府许可、能自己酿酒，脚店只能从正店进酒来卖。这正好对上「酒水先从外面进货，后来自酿做招牌」的设想。《清明上河图》里虹桥旁就画着一家「十千脚店」，城里有「孙羊正店」。

## 核心循环

**一天**（约 12 分钟现实时间，打开菜单时暂停）：

| 时辰 | 做什么 |
|---|---|
| 卯时（清晨） | 去早市买菜：看今天的菜价，和菜贩讨价还价 |
| 辰～巳时 | 回店备菜，定今天的菜单 |
| 午～未时 | 午市：迎客、点菜、做菜、上菜、收钱，顺便听客人闲聊 |
| 申时 | 空闲：改造店面、雇人、逛街，以后还有研发菜品、请说书 |
| 酉～戌时 | 夜市：宋代汴京有夜市，客人更多、更杂 |
| 亥时 | 打烊：打扫、记账、睡觉（自动存档） |

**长线**：赚钱、攒声望，店铺从「脚店一星」升到「正店五星」。等级越高，来的客人越体面，菜能卖得越贵。之后可以雇厨子、小二、账房，扩建店面，请说书和杂剧艺人，最后拿到酿酒资格，做出自家的招牌酒。

**信息线**：客人闲聊会透露米价涨跌、节庆、官员来访、天气、边关战事、科举放榜等消息，这些会影响之后几天的菜价和客流。会听的老板赚得多。

## 世界与编辑器（你说的「开放世界平台」）

- **世界**：一片可以自由走动、大小有限的宋代城区，比如虹桥一带的汴河两岸，有街道、早市、码头、桥、民居和田野。地图的大小和内容由你在编辑器里决定。
- **编辑器**：在电脑浏览器里用鼠标操作的工具。
  - 能做的事：铺地面（土路、石板、草地、水面），摆放树木花草、房屋、桥、摊位和家具，标出哪里能走。
  - 结果存成一个地图文件放进仓库，手机上的游戏直接读取。
- **搭场景不花这里的 token**：你用鼠标摆出来的是数据文件。我的 token 主要花在写引擎、编辑器和玩法代码上。图片由你用 ChatGPT 生成，也不占这里的用量。
- **先做编辑器不是绕路**：玩家在游戏里改造饭馆，用的就是这套摆放系统，只是限制在自家店里，而且要花钱。
- **素材导入**：编辑器里有一个导入面板。把 ChatGPT 生成的透明背景图拖进来，标出它占几格、脚底在哪、有多高（这几项决定遮挡关系），之后就能摆放。

## 美术

- **风格 A**：2:1 等距视角、手绘国风，配色是赭黄的土地、黛灰的瓦、朱红的柱子，加少量青绿。参考《清明上河图》的街市（虹桥、彩楼欢门、脚店、正店）和你发的四张参考图。
- **场景物件**（地面、房屋、树、家具、摊位）：由你用 ChatGPT 生成，提示词模板由我写。先做 3～5 张放进游戏试，确认角度、比例、画风统一后再批量做。
- **人物**有两个方案，需要你选：
  1. **代码画**（像样张 A 里的人）：衣服、帽子、发型可以自由组合，客人的花样多；走路、坐下、吃饭的动作都能做。缺点是和 AI 画的场景放在一起，画风可能有差距。
  2. **AI 画**：每种人画正面、背面、坐姿 3 张，走路时用代码让它上下颠动。画质更统一，但客人种类受图片数量限制，动作也比较僵。

  我建议用方案 1。重要角色（熟客、员工）另外用 AI 画对话时的半身立绘。
- **文字一律由代码写**：招牌、菜牌、对话都不让 AI 画字，因为 AI 写的汉字常出错。
- **时代考据**：不出现辣椒、玉米、土豆、番茄，这些宋代还没有。样张里的「阳春面」「女儿红」是后世的叫法，做内容时会换掉。
